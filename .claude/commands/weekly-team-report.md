# チーム週次まとめ 自動生成スキル

各チームの1週間の活動をNotionの議事録・タスク・作成ページから**自動で拾い**、週次まとめを生成してリーダー報告会ページに記入する。
メンバーに記入を求めるのではなく「記録から拾う」のが設計思想。記録が見つからないチームは「今週の記録なし」と明示し、リーダー会での口頭確認を最小化する。

**AI自走の原則**: 実行中にユーザーへ質問して止まらない。情報が見つからなければ「記録なし」と書いて先に進む。推測で事実を作らない。

## 引数

$ARGUMENTS

- `all`（または空）: 全4チーム分を作成
- チーム名（`スープ` / `消費者` / `クリエイティブ` / `バックオフィス`）: そのチームのみ
- 日付範囲が指定された場合はその範囲。なければ前週火曜〜今週月曜。

## 手順

### 1. 対象期間の特定
リーダー報告会は毎週火曜の夜に開催し、このまとめは前日の月曜までに作る。
対象期間は**前週火曜〜今週月曜**（前回のリーダー会以降に起きたこと）。月曜に実行した場合は「先週火曜〜今日」になる。

### 2. 情報収集
上記ソースを対象期間でクエリ・検索し、各チームの「やったこと」「決まったこと」「未完了タスク」「困りごと」を抽出する。前回のリーダー報告会ページ（中央議事録DBで「リーダー報告会」を検索、直近のもの）も読み、先週の「次週やること」との差分（できた/できていない）を把握する。

### 3. KPIの照合
KPIトラッカーDB `collection://27dd4f82-7cdb-471f-91f0-6c28f02237a6` から当該チームの週次KPI（対象期間が今週のもの）を取得。議事録等から実績値が読み取れる場合は実績値・ステータスを更新する。読み取れない場合は触らない。

### 4. 週次まとめページの作成
- **スープチーム**: 🗓 スープ議事録・週次まとめDB（`collection://0824314c-8c24-4391-a061-31bc347e5acc`）に作成
- **その他のチーム**: 中央議事録DB（`collection://30591268-b898-803c-b2f0-000b13fb9581`）に作成。ミーティング名=`{チーム}チーム 週次まとめ（{開始日}〜{終了日}）`、日付=終了日

フォーマット:
```
## ✅ 今週やったこと
- **日付**: 事実ベースで（推測・計画は書かない）

## 📊 KPI
テーブル（指標 | 目標 | 実績 | 状態）※KPIトラッカーDBから

## ⏳ 先週の宿題の消化状況
テーブル（やること | 状態 ✅/❌ | 備考）

## ⚠️ 困りごと・ボトルネック
callout形式で最大3個（解決しないと先に進めないものだけ）

## ➡️ 次週やること
テーブル（やること | 担当 | 備考）
```

### 5. リーダー報告会ページへの記入
当日のリーダー報告会ページ（中央議事録DBで検索）が存在する場合、該当チームのセクションに簡潔に記入する:
- 今週やってきたこと（箇条書き3〜5個）
- 困っていること（あれば）
- 次週までにやろうとしていること（3〜5個）
- 末尾に `（Notionの記録から自動生成）` と付記

該当チームの記録が対象期間に見つからなかった場合は、セクションに `⚠️ 今週のNotion記録が見つかりませんでした。口頭で補足してください` と書く。

## 注意事項
- 日付を必ず記載する。事実ベースで書き、推測を混ぜない
- 記録がないことは「ない」と正直に書く（これが口頭確認の対象を絞る仕組み）
- 前週との差分がわかるように書く
- 旧チーム名（すりながし等）は出力に使わない
