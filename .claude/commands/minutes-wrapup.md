# 議事録まとめスキル

会議直後に、議事録ページのアジェンダと走り書きメモから **①今日決まったこと ②残った議題 ③各自のタスク（表）** を作り、そのページに書き込む。
設計思想は「会議中に書けなかった分を、記録から拾って整形する」。新しい事実を足すのではなく、**散らばった記述を決定・未決・タスクの3つに振り分ける**のが仕事。

**AI自走の原則**: 実行中にユーザーへ質問して止まらない。担当・期限が分からなければ「記録なし」と書いて先に進む。**推測で担当者や期限を埋めない。**

## 引数

$ARGUMENTS

- 議事録ページのURL または ページID → そのページを対象にする
- 空 → 今日の日付の議事録を探す。スープチームの定例なら 🗓 スープ議事録・週次まとめDB `collection://0824314c-8c24-4391-a061-31bc347e5acc`、それ以外は中央議事録DB `collection://30591268-b898-803c-b2f0-000b13fb9581`。見つからなければ「今日の議事録が見つかりません」と報告して終了（新規作成はしない）

## 手順

### 1. ページを読む
`notion-fetch` でページ全体を取得する。`<ancestor-path>` で親DBを確認し、リンクされている資料ページ（決定事項・たたき台・確定版など）も必要なら開く。
**書き込む前に `notion://docs/enhanced-markdown-spec` を読む。**表や日付メンションの記法を推測で書かない。

### 2. 《決めたいこと》を全部洗い出す
アジェンダの各セクション（①②③…）にある「《決めたいこと》」「《聞くこと》」を列挙する。**これが「残った議題」の判定リストになる。**

### 3. 記入の有無で3つに振り分ける

| 状態 | 行き先 |
|---|---|
| 《決めたいこと》に対する答えが書かれている／「決まったこと」と明記されている | ✅ 今日決まったこと |
| 《決めたいこと》が未記入、表の担当欄・回答欄が空欄 | 🪧 残った議題 |
| 担当者名がついた作業・走り書きのメモ | 📮 各自のタスク（表） |

- **ページ末尾の走り書き（箇条書きや素のメモ行）は1つも捨てない。** 決定なら①へ、作業なら③の表へ移す
- 会議で決まった内容が資料のたたき台と食い違う場合は、**決定を採用し「たたき台の◯◯から変更」と括弧で明記する**（例: 価格が資料と違う）
- 一部の人だけ記入されている表（1人ずつ聞くセクション等）は「決まった」と書かない。**記入済みの内容を事実として引用し、未記入者と最終決定は残った議題に回す**

### 4. 書き方のルール
- **担当・期限が不明は「記録なし」**。空欄のまま消さない。期限が空のタスクも表に残す（落とすと忘れられる）
- 「明日22時」「今週」などの相対表現は、**議事録の日付を基準に絶対日時へ直す**。日付・時刻は日付メンションにする（例: `<mention-date start="2026-10-09" startTime="22:00" timeZone="Asia/Tokyo"/>`）
- 名前は議事録の表記のまま（ひらがな）。旧チーム名（すりながし／アグリパートナー／飲食店／カスタマーリレーション／ベジコベ）は使わない
- 残った議題は**「どのセクションの何が未決か」を頭に置く**（例: 「③ 11月の営業日：曜日・時間・店番が未記入」）。期限が付いているものは期限も書く
- 数字（金額・人数・杯数）は議事録の数字をそのまま使う。丸めない・計算し直さない

### 5. 書き込む（既存の記述は消さない）
`notion-update-page` の `update_content` で**最小編集**する。`replace_content` でページ全体を置き換えない。

- 置き換え対象は**プレースホルダー（「（会議中に記入）」など）と、末尾の走り書きだけ**
- **会議中に人が書き込んだ内容は絶対に上書きしない**（アジェンダ本文・表の記入済みセル・メモ）
- 見出しは `# ✅ 今日決まったこと` / `# 🪧 残った議題` / `# 📮 各自のタスク` の3本。既に同名の見出しがあればその中身を差し替える
- タスク表の列は **タスク／担当／期限／備考** の4列固定（`<table fit-page-width="true" header-row="true">`）
- 書き込み後に `notion-fetch` で読み直し、表が崩れていないか・走り書きが二重に残っていないかを確認する

### 6. チャットにも同じ3点を返す
Notionに書いた内容と同じものを、箇条書き＋表でチャットにも出す（ページを開かずに確認できるように）。あわせて**最後に必ずこの2つを警告として挙げる**:

1. **担当が「記録なし」のタスク**（宙に浮いている作業）
2. **期限が今日・明日・今週のタスクと、担当が空の期限付き項目**（取りこぼすと間に合わないもの）

### 7. 記録とのズレを報告する
議事録に、`knowledge/` の記録と食い違う事実（営業日・価格・会員数・固定費・契約期間など）が出てきたら、**勝手に書き換えず**、実行結果の最後に「記録と実態のズレ」として列挙し、`knowledge/` の更新を提案する。更新してよいかはユーザーの判断。

## やらないこと

- 新しい議事録ページを作る（このスキルは既存ページの整形のみ）
- 会議で出ていない打ち手・結論を足す
- 担当者を勝手に割り振る、期限を勝手に設定する
- 「要検討」「適宜対応」のような中身のない行をタスク表に入れる
- 撤退・中止済みの事業（`CLAUDE.md` §2）を前提にした書き方をする

## 出力例（2026/10/08 スープチーム定例の実績）

- ✅ 決まったこと: 商大祭のメニュー変更が承認／価格を「スープ500円・大学芋300円・セット700円」に決定（たたき台の400円・850円から変更）／冷凍ベースの残りを使う
- 🪧 残った議題: ② 大分類の絞り込み（まい・この＝A、他は未記入）／③ 11月の営業日（曜日・店番・案出しの担当が未記入）／④ 認知対策の担当欄が空欄（LINE配信は期限「今日」）
- 📮 タスク表: 商大祭用のぼりのデザイン＝まい・期限記録なし／手書き風看板を作る会＝まい・りょうすけ・さがりん・10/9 22:00／部員名簿の提出＝りょうすけ・期限記録なし
