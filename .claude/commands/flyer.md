# チラシ作成スキル（/flyer）

りふぁーむの配布チラシを、**印刷可能なHTML（@page指定）→ Chrome headlessでPDF化**の型で作成する。
実例（生きた見本）: **`flyers/2026-07-10_coop_soup_A5_v2.html`（写真ヒーロー版・これが目標品質）** ／ `flyers/2026-07-10_okaeri_noen_A4.html`（おかえり農園シニア向け・A4）。**迷ったらv2の構造を流用する。**

## 🚨 最重要：品質はツールでなく「写真素材」で決まる（2026-07-07の学び）
- CSSの色丸・アイコンで写真を代用したチラシは**必ず安っぽくなる**（Canva級にならない）。原因はHTML/CSSでもMarpでもなく**素材**。
- **必ず実写または生成写真をヒーローに使う**。りふぁーむには写真生成パイプラインがある：
  - 既存の料理写真: `flyers/img/soup_hero.png`（見本用）。実写の正はGoogleドライブ「50日企画素材/Googleビジネスプロフィール」
  - 生成スクリプト: `tools/generate_image.py`（APIキーは環境変数 GEMINI_API_KEY）（**Gemini `gemini-2.5-flash-image`**。元写真＋プロンプトで料理・農園・人物写真を生成／編集）。のぼり・スライド画像も同方式
  - 素材が無いテーマ（トマトスープ・とうもろこしスープ・農園風景・シニアが畑で笑う等）は、まず generate.py を複製してプロンプトを書き換え、`flyers/img/` にヒーロー写真を生成してから組む
- Marpに乗り換える必要はない（Marpはスライド向けで自由度が低い）。**HTML/CSSが正**。プロも印刷物はInDesign／HTMLで、Canvaの弱点は「テンプレ感」。写真＋余白＋タイポの作り込みで越えられる。

## 引数

$ARGUMENTS

引数＝チラシのお題（例:「8/12オープン告知」「体験会の次回チラシ」）。
空の場合は「何のチラシですか？（イベント・配布場所・対象者・伝えたい1つのこと）」と確認する。

## ブランド別デザイントークン

| ブランド | 背景 | アクセント | 見出し | 見本 |
|---|---|---|---|---|
| **スープ** | 白 `#FFFFFF`／サブ `#FBF7F3` | コーラル `#E86A6F`（押し色 `#D45960`） | 明朝（Yu Mincho）、本文ゴシック | soup_A5 |
| **おかえり農園・りふぁーむ全般** | 紙 `#FBFAF6` | 緑 `#2F6B45`（差し色の暖赤 `#C0533F`） | 明朝、本文ゴシック | okaeri_A4 |

共通ルール: 黒ベタ・緑ベタ背景はNG。マーカー強調は淡黄 `#F3E4A8`（緑系）/ 淡黄 `#FFF3B8`（プレースホルダー用）。

## サイズと対象者の目安

- **店頭手渡し・イベント配布** → A5（148×210mm）
- **シニア向け** → A4（210×297mm）＋ **本文10pt以上・見出し大きく・電話番号を主導線に**（LINE/QRは補助）
- 掲示用ポスター → A4〜A3

## 必須要素チェックリスト（作成後に必ず確認）

- [ ] **写真ヒーローがあるか**（最重要。無ければ生成する。色丸・アイコンで代用しない）
- [ ] **5W1H**: 日時・場所・価格（無料なら「無料」を目立たせる）・持ち物
- [ ] **主催者名**（学生団体りふぁーむ〔兵庫県立大学〕）と**連絡先**（メール/電話）
- [ ] **CTA1つ**（公式LINE登録 or 電話申込。欲張って2つ以上主役にしない）
- [ ] **QR貼付欄**: 実QR画像がなければ点線枠 `border: dashed` の「QRコード（貼付欄）」を置く
- [ ] **未確定情報は `<span class="placeholder">〇〇（要記入）</span>`（黄色マーカー）で明示**。勝手に埋めない
- [ ] スープ関連: **効能表現NG**（「効く・改善」禁止。事実表現のみ）、アレルゲンは店頭表示シール参照の注記
- [ ] イベント: 雨天時の扱い・締切・定員の但し書き
- [ ] シニア向け: 漢字にやさしい言い回し・「手ぶらでOK」等の不安払拭ブロック

## 実装の型（印刷CSS）

```css
@page { size: 148mm 210mm; margin: 0; }   /* A5。A4は 210mm 297mm */
body { width: 148mm; height: 210mm; overflow: hidden; }
.page { width: 148mm; height: 210mm; padding: 7mm 9mm; display: flex; flex-direction: column; }
.page > * { flex: none; }   /* ⚠️ 必須（下記の落とし穴1） */
```

### ⚠️ 実制作で踏んだ落とし穴（必ず回避する）

1. **固定高さの flex コンテナは、内容が溢れると子要素を勝手に圧縮する**（`flex-shrink` 既定1）。セクションの中身が消えたように見える事故になる → `.page > * { flex: none; }` を必ず入れ、収まらない分は余白・フォントサイズで調整する
2. **プレースホルダー（黄色ハイライト）を濃色帯の上に置くと白文字で読めなくなる** → `.placeholder { color: #1F1A17; }` と文字色を固定する
3. **フッターが用紙下端ぎりぎり**になりやすい → 最後に必ずスクリーンショット検証し、下端に2mm以上の余白を確保

## 写真の生成（ヒーローが無いとき）

`tools/generate_image.py`（APIキーは環境変数 GEMINI_API_KEY） を `flyers/img/` 向けに複製し、`prompts` を差し替えて実行する（Gemini `gemini-2.5-flash-image`）。プロンプトの型：
- 料理: 「�య の写真を、明るいオフホワイトの台・斜め30度・自然光・湯気・文字/ロゴなし・食欲をそそるフードフォト・1:1」＋「中身は変えない（KEEP contents）」
- 農園/人物: 「神戸郊外の畑・朝の光・とうもろこし・自然な笑顔（シニア）・ドキュメンタリー調・文字なし」
- 元写真がある場合は編集（INPUT_IMAGE指定）、無ければテキストのみ生成に切替。生成後 `flyers/img/` に保存し `<img>` で全面配置（object-fit:cover＋グラデ overlay＋明朝白文字＝v2の型）。

## 検証→PDF化（必須手順）

```bash
# 1. スクリーンショットで目視検証（--force-device-scale-factor=2 で高精細。--allow-file-access-from-files で画像を読む）
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless --disable-gpu \
  --allow-file-access-from-files --force-device-scale-factor=2 --window-size=575,795 \
  --screenshot="{scratchpad}/flyer_check.png" "file:///$(pwd)/flyers/{ファイル名}.html"
# → Readで画像を開き、①写真の見栄え ②全セクション表示 ③文字の可読性 ④下端余白 を確認。問題があれば修正して再検証

# 2. 問題なければPDF化（写真を読むため --allow-file-access-from-files を付ける）
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless --disable-gpu \
  --allow-file-access-from-files --no-pdf-header-footer \
  --print-to-pdf="$(pwd)/flyers/{ファイル名}.pdf" \
  "file:///$(pwd)/flyers/{ファイル名}.html"
```
※印刷解像度：ヒーロー写真は**長辺1600px以上**を用意（A5全面で約300dpi）。生成時に大きめサイズで出す。最終入稿でCMYK変換が要る場合は印刷所の指定に従う（家庭用・コンビニ印刷はRGBのままでよい）。

## 出力先・命名

- `flyers/{YYYY-MM-DD}_{イベント名}_{サイズ}.html` と同名 `.pdf`
- 完成したら、ユーザーに**要記入箇所（黄色マーカー）の一覧**を必ず報告する（店舗名・価格・電話番号・QR等）

## 構成のベストプラクティス（2枚の見本から）

1. キッカー（小さな英字/一言）→ 明朝の大見出し（情緒コピー）→ リード
2. イベント帯 or イベント詳細ボックス（日時・場所は表形式が読みやすい）
3. 商品/体験の紹介（カード2〜3枚。写真の代わりに色スウォッチ円でも成立する）
4. 「わたしたちについて」（想いを1段落。りふぁーむは想い重視）
5. CTA（LINE QR or 電話）— 枠線で囲って最後に一番目立たせる
6. フッター（主催・注意書き）
