# のぼりの目的と、入れる情報（2026-10-09 検証）

## のぼりの目的
通りがかりの人に **「何屋か」を2〜3秒で伝えて、足を向けさせる** こと。買うかどうかの判断はブース前の看板がする。だから、のぼりに価格表や説明を詰めても読まれない。制作会社・屋外広告の実務的な助言は一致していて、要点は次のとおり（出所：[のぼりの基本（マネーフォワード）](https://biz.moneyforward.com/restaurant/basic/3670/)、[屋外表示の可読性ガイド（Daktronics）](https://www.daktronics.com/web-documents/lit/dd3289018.pdf)）。

- 見る時間は数秒。**メッセージは1つ**、文言は短く（商品名か、商品の一番の魅力を一言）
- **文字はできる限り大きく**。見る人は動いている
- **背景と文字のコントラストを強く**（白地に濃色、濃色地に白）。縁取りや影は可読性を上げる
- フォントは**2種類まで**
- 写真は小さく全体を入れるより、**主役を大きく**
- 裏から見ると左右反転する。風ではためく。遠くからは細部が消える → 細い線・小さい文字は無意味

## 文字の大きさの目安（屋外表示の経験則）
文字の高さ ≒ 読ませたい距離 ÷ 250〜300。10mで読ませるなら文字高さ約4cm、20mなら約7〜8cm。のぼり（幅60cm）に縦書きで1行なら、1文字12〜20cm（4〜7文字）が実用的。

## のぼりに入れる情報（優先順）
1. **店の主力商品名**（VEGEONEなら「焼き芋スープ」）… 必須。これだけで成立する
2. **一番の魅力を一言**（例：ホイップかけ放題）… 帯や袋文字で添える
3. **2つ目の商品**（例：揚げたて大学芋）… 小さめ
4. **ブランド**（VEGEONE）… 下に小さく
5. 価格 … 入れるなら1行で。入れなくてもよい（看板が受け持つ）
入れないもの：日付、説明文、産地の細かい話、QR、複数のキャッチコピー

## いちばん速い道：既存ののぼりの「差し替え版」を作る
VEGEONEには完成済みの通年のぼり（`vegeone_nobori/nobori_line.py`＝コーラル地・丸ごと野菜スープ・線画・スプーンのカップ・白地ロゴ）がある。季節商品や学祭用は**新しく作らず、この骨格のまま写真と文言と線画だけ差し替える**（例：`vegeone_nobori/nobori_imo.py`＝さつまいも版、2026-10-09）。
手順：①商品写真をグリーンバックで生成して切り抜く（`common.key_green`）②線画が要るなら黒地に白線で生成→`vegeone_nobori/trace_lineart_imo.py` の要領でSVGパス化③`nobori_imo.py` をコピーして見出し・リボン・線画・写真を書き換える④`python nobori_imo.py` → PDF（Chrome headless・原寸）。

## 進め方（手戻りを減らす）
1. **先に手本を2〜3枚もらう**（「こういうのがいい」の実物）。AIが一から作って直すより、手本から作る方が早い
2. 手本を `reference/examples/` に入れ、どの型かを決める
3. 文字を決める（商品名・一言・2つ目・ブランド）
4. 型のスクリプトで出す → 1つずつ直す
5. 印刷：600×1800mm、100dpiで2362×7087px。上と左のチチ（20〜30mm）に文字をかぶせない。印刷会社のテンプレートがあればそれに合わせる
