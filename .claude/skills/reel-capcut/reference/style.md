# りふぁーむ動画の様式（これに合わせないと「別のもの」になる）

1本目「５０日企画　１」をフレーム実測し、ゆうと編集版（間借り編2_v5）から実IDを採取して確定したもの。
**plan.json を書く前に必ず読む。** ここに書いてあることは提案ではなく決まり。

## 1. 骨格 — 全本共通

| 位置 | 素材 | ルール |
|---|---|---|
| **最初** | `オープニング.mp4` | 必ず1本目。ナレーション `オープニング.m4a` を当てる |
| 本編 | 台本のセリフ1行 = 1セグメント | クリップ2〜3本／1本2.5〜5秒 |
| **最後** | `エンディング.mp4` | 必ず最後。ナレーション `エンディング.m4a`（あれば） |

OP/EDは `G:\マイドライブ\50日企画素材\_共通素材\OP_ED\`（無ければ `7 14 素材\`）にある。
**OPとEDを外した動画は「りふぁーむの動画」に見えない。** 台本に書いてなくても付ける。

## 2. テロップ

### フォント
- **コーポレート・ロゴ（ラウンド）ver3 Bold**（CapCut内フォント「企業」・ID `7532058832042790161`）
- `make_draft.py` が自動で設定する。**CapCutで開いて既定ゴシックになっていたら、全選択→フォント「企業」に一括変更**
- 強調アクセント（まれ）: 思源黒体 Heavy・紫 RGB(0.584, 0.435, 0.902)

### 色・縁・大きさ
- **白字＋黒縁**（CapCut: size 13・bold・stroke 0.08）
- **強調行だけ黄**（`color: yellow` = #FFD633）。1セグメントに強調は0〜1行
- 出現アニメーションは付けない（カット頭で即表示）

### 配置
- **通常テロップ: 画面下1/3・中心 y=1340**（1080×1920基準）。2行なら行間130で上下に振る
- **OPだけ2段**: 上段 y=231（「◯日後に三宮に」など前半）／下段 y=1193（「スープ屋を開く大学生」など後半）。上段 0.35秒〜、下段 1.6秒〜
- 中央揃え

### 割り方（ここを外すと一気に素人っぽくなる）
- **1カード = 台本の1フレーズ（1〜2行、1行10文字目安）**。セリフ1行を丸ごと1枚にしない
- カードの切り替わりは**ナレーションのその言葉が出る瞬間**に合わせる。`at`/`until` を音声で実測して書く
- 決めゼリフの行だけ黄。「うまくできませんでした」「捨てるところはありません」のような**結論の行**

```json
"telop": [{"at": 0,   "until": 3.1, "lines": ["正直に言います"]},
          {"at": 3.1, "until": 6.6, "lines": ["思ってたより", "うまくできませんでした"], "color": "yellow"},
          {"at": 6.6,               "lines": ["出汁の旨味も", "消えちゃってる"]}]
```

## 3. 効果音（CapCut公式ライブラリの実音源）

`G:\マイドライブ\50日企画素材\_共通素材\SE_CapCutライブラリ\` の mp3 を使う。自作の合成音は使わない。

| 場面 | 音 | volume |
|---|---|---|
| パンチライン・強い断定 | `ドーン.mp3` / `どどん.mp3` | 0.7 |
| 落ち込み・失敗の告白 | `ピアノ、がーん、ショック、落ち込む.mp3` | 0.55 |
| 前向き反転・決意・CTA | `シャキーンとポーズを決めるイメージ.mp3` | 0.55 |
| 画面イン・小さいキメ | `シャキーン（ドキュイーン）.mp3` | 0.5 |
| 結果発表のタメ | `SE_ドラムロール.wav` → 答えの瞬間に写真をバンッ | 0.5 |

**置き方**: 1本に3〜5個。テロップの黄行が出る瞬間か、表情が変わる瞬間に置く。多いと安っぽい。

## 4. カットの質感

- **縦1080×1920に「覆う」**（cover）。横長素材は拡大して黒帯を出さない。`make_draft.py` が自動でやる
  - 例外: 画面録画・切れてはいけない絵は `"fit": "contain"` を指定し、事前にぼかし背景合成を作る（reel-build参照）
- **現場音はミュート**（ナレーションと混ざる）。OP/EDだけ素材音を残す
- クリップの `offset` は**動作の始まる直前**に置く（腕組みなら腕を組み始める0.3秒前）
- ナレーションの言葉と画の**動作を重ねる**（「教えてください」で手を差し出す等）。ここが一番手間で一番効く
- セグメント間: 白フラッシュが基本。落ち込み区間の出入りだけ黒
- ネタバレ（投票結果等）は言う瞬間まで出さない

## 5. 音

- 録音は台本1行=1ファイル。`.m4a` は取り込み時に自動でノイズ除去
- 行頭・行末の無音は短く録る（長いと間延びする。CapCut上で詰めてもらう）
- 最終ラウドネス目安 -16 LUFS（焼き込み時。ドラフトはCapCut側）

## 6. やらないこと

- OP/EDを省く／別のOPを作る
- フォントを変える（明朝・細ゴシックは即NG）
- テロップを1セグメント1枚で出しっぱなしにする
- 全行を黄にする／全カットにSEを置く
- 横長素材を黒帯のまま置く
- 台本に無い演出を足す（台本が正。直したいときは台本を直す）
