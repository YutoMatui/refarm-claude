# 新しいパソコンで使えるようにする（1回だけ）

メンバーが自分のパソコンで動画を作れるようにするための準備。
**ここはゆうとか、パソコンに慣れている人が一緒にやる。**30分くらい。

## 1. アプリを入れる

| 何 | どこから | 確認のしかた |
|----|---------|------------|
| CapCut（デスクトップ版） | capcut.com | 起動して**新規プロジェクトを1つ作る**（これが後で骨格に要る） |
| Googleドライブ（パソコン版） | google.com/drive/download | エクスプローラで `G:\マイドライブ` が開ける |
| Python 3.11以上 | python.org | インストール時に **Add python.exe to PATH にチェック** |
| ffmpeg | ffmpeg.org（gyan.dev版） | 解凍して `bin` を PATH に追加 |
| Claude Code | claude.com/code | ターミナルで `claude` |

確認:

```bash
python --version && ffmpeg -version | head -1 && ls "G:/マイドライブ/50日企画素材" | head -3
```

## 2. ライブラリを入れる

```bash
pip install pyJianYingDraft
```

## 3. このフォルダを持ってくる

```bash
git clone https://github.com/<りふぁーむのリポジトリ> refarm-cc-company
```

Claude Code はこのフォルダの中で起動する。`.claude/skills/` にスキルが入っているので、
このフォルダで起動しないとスキルが読み込まれない。

## 4. 共通素材（コピー不要・Driveにある）

効果音・オープニング／エンディング・フォントは **`G:\マイドライブ\50日企画素材\_共通素材\`** に置いてあり、
スクリプトが自動で拾う。自分のパソコンにコピーする必要はない。

```
_共通素材\
├── SE_CapCutライブラリ\   効果音5本（CapCut公式ライブラリの実音源）
├── OP_ED\                オープニング.mp4 / エンディング.mp4
└── フォント\             メインテロップ.ttf（コーポレート・ロゴ ラウンド ver3 Bold）
```

**テロップのフォントだけ1回手を動かす**: CapCutを開き、適当なテキストを置いて、フォント一覧から
「企業」を一度選ぶ。これでフォントの実体がCapCutに落ちてきて、以後は自動で付く。

## 5. 生成AIを使う場合だけ：APIキー

**素材が足りないカットを画像から動かすときにだけ要る。**使わないなら飛ばしていい。

キーはゆうとから直接もらって、自分のパソコンに1回だけ登録する。
**チャットに貼らない・ファイルに書かない・GitHubに上げない。**

PowerShellで:

```
setx GEMINI_API_KEY "（もらったキー）"
```

そのあとターミナルを開き直す。確認:

```bash
python .claude/skills/reel-capcut/scripts/gen_clip.py 見積
```
