# 様式②「飲食店」（2026-10-10 ゆうと指示：学生っぽさより、きちんとしたおしゃれな飲食店の表現に）

従来の様式①（`style.md`＝50日企画：コーポレート・ロゴ丸ゴ・白字黒縁・OP/ED・効果音）は**連載ドキュメンタリー用**。
店のメニュー紹介・営業日・行き方・作り方の動画は、この様式②で作る。看板・広告（creative-kv）と同じ文字組にそろえる。

## 1. 骨格
- **OP/EDは付けない。** 最初の0.5秒で商品が動いている（注ぐ・湯気・割る）。最後は商品の静止カット＋店の情報1枚（3秒）
- カットは2〜4秒。早回しは工程だけ。白フラッシュや派手なトランジションは使わない（カット or 0.3秒のディゾルブ）
- **効果音なし。** CapCutライブラリの効果音（シャキーン等）は店の動画には合わない（2026-10-11 代表確認）。現場の音が汚ければ素材音も消し（plan `"mute_clips": true`）、BGMだけを Instagram か CapCut で付ける
- ナレーションは原則なし（入れるなら小声の独り言）。文字で読めれば成立する

## 2. 文字
| 要素 | フォント | 大きさ（1080×1920） | 色 | 置き方 |
|---|---|---|---|---|
| 見出し・商品名 | **Shippori Mincho Bold**（`fonts/ShipporiMincho-Bold.ttf`・OFL。PCに HG明朝E があればそれでも可） | 72〜96px | クリーム `#FFF7E6` | 中央揃え・字間 0.08em・**縁取りなし**・柔らかい影（ぼかし8・不透明60%） |
| 一言・補足 | Shippori Mincho SemiBold | 36〜44px | ゴールド `#FFD68C` か クリーム | 見出しの下 |
| 数字・時刻・価格 | **Bookman Old Style**（Windows同梱）か Shippori の数字 | 見出しと同じ | クリーム | 「11:00 – 14:00」「¥500」 |
| 心の声（vlog） | Shippori Mincho SemiBold | 40px | クリーム | 下1/3・句点なし・10文字以内 |
| 使わないもの | ゴシック太字＋白縁取り／赤丸バッジ／黄色の強調／ポップ体／絵文字 | | | |

- 1画面の文字は**2行まで**。情報は「商品名・一言・価格か営業日・場所」の4つで足りる
- 文字の後ろは、画面の上下にうっすら暗いグラデーションを敷いて読ませる。帯や箱は使わない。背景動画を `prep_clip.py --shade 入力 出力` に通すと上30%・下12%が暗くなる（CapCut でも読みやすい）。文字は下1/4に置かない（Instagram のプロフィール欄と重なる）。CapCut の文字には柔らかい影（make_draft が自動で付ける）

## 3. 色・画
- 地色が要るときはブランドの色から：秋＝金色グラデ（`#D59040→#B86A1E`）、通年＝コーラル（`#E86A6F`）か生成り（`#FBFAF6`）
- 写真は実物。明るい窓際・白いカップ・真上と斜め45度。生成画像は背景や季節感だけ
- ロゴは最後の1枚にだけ（`creative-kv/scripts/brand.py` のワードマーク）。カップのシールで十分見えている

## 4. 作り方（2026-10-10 ゆうと指示の順番：背景動画 → CapCutでつなぐ → 文字はCapCutで後入れ）
静止画をつないだだけの動画は「動いていない」と見える。**各カットをまず文字なしの背景動画にして、文字はCapCut上で入れる**。こうすると、メンバーが文字だけ直せる。

1. **背景動画を用意する（文字なし・1080×1920・各3〜8秒）**
   - 実写があるもの → そのまま使う（店の前の人物、外観、注ぐ・盛る手元）。縦1080×1920に `ffmpeg` で揃える
   - 絵はあるが動きがないもの（キービジュアル・商品写真）→ **画像から動画生成**で動かす。`scripts/gen_clip.py 実行 出力.mp4 元絵.png "動きの指示"`（Veo 3.1 fast・8秒・約180円・月上限3,000円の台帳つき）。元絵は先に9:16に切っておく。指示は「動かすもの1つ＋湯気」くらいに絞る（例：蜜が上から垂れて流れる／湯気が立つ・もみじが1枚落ちる）。無料でやるなら Dreamina か CapCut の AI動画生成（Seedance 2.0・毎日の無料クレジット）に同じ元絵と同じ指示を入れる
   - カレンダー・ロゴなど図形で作るもの → Pillowで1コマずつ描いて動かす（例：`video/cal_reel/build_bg.py`。営業日が1つずつ出る・カップが滑り込む）
2. **plan.json を書いて CapCut ドラフトにする**：`"style": "restaurant"`、音声なしのセグメントを1クリップずつ並べ、telop に文字を書く → `python scripts/make_draft.py plan.json`。文字は CapCut のテキストとして入るので、CapCut上で直せる（フォントが既定ゴシックのままなら全選択→「Shippori Mincho」）。例：`video/cal_reel/plan_restaurant.json`
3. **CapCutで仕上げる**：カットの間に 0.3秒のディゾルブ、BGMを小さく（OpenTracks等の無料曲）、現場音は残す。書き出し 1080p
4. 確認用の mp4 がすぐ欲しいときは `python scripts/render_mp4.py plan.json 出力.mp4`（同じ plan から焼き込み。縁取りなし・影つきで出る）

- 例：`完成動画/10月の営業日_リール_restaurant.mp4`（2026-10-10。1本目＝静止画版）→ `10月の営業日_v2_背景動画版.mp4`（Veoで動かした版）
