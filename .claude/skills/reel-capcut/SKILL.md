# 台本 → CapCutドラフト（メンバー向け）

Notionに書いてある台本のリンクを渡されたら、CapCutで開ける状態にして返す。
**基本はCapCutドラフトで渡す。** テロップの微調整・カットの詰めはメンバーがCapCut上でやる前提。
「mp4もください」と言われたときだけ、同じ plan.json から `render_mp4.py` で焼き出す（ドラフトと同じ割り付け・同じフォント）。

技術的な細部（ffmpegのフィルタ・ネイティブ化の理屈・焼き込みレンダリング）は
`reel-build` スキルに書いてある。**このスキルは「人に使ってもらう手順」の側**。
完成品まで自分で書き出すときは reel-build を見る。

## 相手はコードを書かない人

学生メンバーが使う。**コードやパスの話をこちらから振らない。** 聞くのは
「この素材とこの素材、どっちを使いますか」のような、見ればわかることだけにする。
エラーが出たら、原因を日本語で説明して、こちらで直す。

## 様式は決まっている（最重要・ここを外すと別の動画になる）

**`reference/style.md` を最初に読む。** 1本目の動画を実測して決めた様式で、提案ではなく決まり。
2026-09-05、これを書いていなかったためにメンバーの環境で「OPが無い・テロップが違う」動画が返ってきた。

守ること（詳細は style.md）:

- **最初は `オープニング.mp4`、最後は `エンディング.mp4`。** 台本に書いてなくても付ける。`make_draft.py` は無いと止まる
- **テロップ＝コーポレート・ロゴ（ラウンド）Bold・白字黒縁・下1/3（y=1340）・決めゼリフの行だけ黄。** OPだけ上段 y=231／下段 y=1193 の2段
- **1カード＝台本の1フレーズ（1〜2行・1行10文字）。** セリフ1行を1枚で出しっぱなしにしない。切り替わりは音声のその言葉の瞬間
- **効果音はCapCut公式ライブラリの5本だけ・1本に3〜5個。** ドーン＝パンチライン／ピアノがーん＝落ち込み／シャキーン＝前向き
- **横長素材は縦画面を覆う（黒帯を出さない）。** `make_draft.py` が自動でやる。画面録画だけ `"fit": "contain"`
- **台本が読めない・音声が無い・素材が無いときは止まって言う。想像で埋めない。** 台本に無い演出も足さない

## 手順

### 0. 動く状態か確かめる（初回・うまくいかないとき）

```bash
python scripts/setup_check.py
```

○×で出る。**× が1つでもあれば台本の話に進まない。** → の通りに直してもらう
（Drive・CapCut・ffmpeg・共通素材（効果音／OP・ED／フォント）・APIキーを見る）。
新しいPCの準備は `reference/setup.md`。

### 1. 台本を読む

NotionのURL（またはページ名）をもらって `notion-fetch` で開く。
台本は「セリフ／画・素材」の2列の表になっている。ここから拾うのは:

- **セリフ** … ナレーション1行 = 1セグメント
- **画・素材** … 🎥現地＝新規撮影が必要／♻️既存＝撮影済み素材／🔁汎用＝OP/CTA
- 表の下の**素材リスト**に、ファイル番号（`1787` `IMG_3480` 等）が書いてあることが多い

> 台本ページに「🆕 改訂版」が付いていたら**改訂版のほうを使う**。上の初版は履歴。

### 2. ナレーション音声を探す

`G:\マイドライブ\50日企画素材\音声素材\<企画名>\` に、台本1行 = 1ファイル（.m4a）で入っている。
ファイル名はセリフの冒頭になっていることが多い（`正直にいいます.m4a`）。

**録音がまだなら、そこで止めて「先に録音してください」と伝える。**
音声がタイムラインの土台なので、無いと組めない。台本の行をそのまま読み上げリストにして渡す。

### 3. 映像素材を探す

```bash
python scripts/scan_assets.py                    # 索引を作る（初回・素材を足したとき）
python scripts/scan_assets.py 落ち込み 語り        # ことばで探す
```

台本の「画・素材」欄のことばで引く。ファイル名が `IMG_1234.MOV` のままだと中身で探せないので、
その場合は**中身を見て `IMG_1234_内容.MOV` にリネームしてから**索引を作り直す。

### 4. 割り付けを決めて、見てもらう

ここが一番だいじで、自動化できない。**セリフの意味と画が合っているか**は人が見る。

1セグメント（ナレーション1本）につきクリップ2〜3本、1本2.5〜5秒が目安。
決めたら**表にして先に見せる**。「この2つ、どっちがいいですか」を聞くのはここ。
表には**テロップのカード割りとSEも入れる**（後から足すと様式がぶれる）。

| # | セリフ | 使うクリップ | 秒 | テロップ | SE |
|---|--------|------------|-----|---------|-----|
| 0 | （OP） | オープニング.mp4 | 3.0 | 上「◯日後に三宮に」／下「スープ屋を開く大学生」 | — |
| 1 | 正直に言います | IMG_1787_室内前かがみ落ち込み後ろ姿 | 3.5 | 「正直に言います」→「思ってたより／**うまくできませんでした**」 | ドーン @3.1 |
| … | | | | | |
| 9 | （ED） | エンディング.mp4 | 4.2 | — | シャキーン |

`offset` は**動作の始まる直前**に置く。言葉と動作が重なるカット（「教えてください」で手を差し出す等）が
1本に1〜2か所あると、ぐっと良くなる。

### 5. 足りないカットを埋める（生成）— お金がかかる

実写が無いカットだけ、静止画から動かす。**動画1本8秒で約180円。**

```bash
python scripts/gen_clip.py 見積                                # 値段と今月の残りを出す
python scripts/gen_image.py 試作 元絵.png "英語のプロンプト" [参考画像...]   # 約6円/枚
python scripts/gen_clip.py 実行 out.mp4 元絵.png "動きの指示"    # 約180円/本
python scripts/cost.py                                         # だれがいくら使ったか
```

**必ず守ること:**

- **実写が1本でもあるなら実写を使う。** 湯気も表情も本物のほうがいい。
- **生成する前に、何本 × いくらかを表にして見せ、はっきり「はい」をもらう。** 黙って回さない。
- **1カットにつき1回だけ。** 気に入らなければ元絵かプロンプトを直す。同じ条件で引き直さない。
- 元絵さがしは `gen_image.py 試作`（6円）。`本番`（20円）は最後の1枚だけ。
- **失敗しても課金される。** 台帳には失敗ぶんも残る。

動きの指示は英語で、**動くものを1つだけ**書く。カメラは固定。
（湯気 `Steam rises continuously in soft curling ribbons.` /
スプーン `A spoon dips in and lets one thick ribbon fall back.`）

#### 課金の記録（勝手に使われないための仕組み）

`scripts/cost.py` が全員ぶんの利用を1つの台帳にためる。
台帳は **`G:\マイドライブ\50日企画素材\_API利用ログ.jsonl`**（Drive上なので全員が同じものを見る）。

- 1件ごとに **だれが・いつ・何に・いくら** が残る。パソコン名まで入るので誰の分か分かる
- 月の上限を超える生成は**実行前に止まる**（既定3000円・`python scripts/cost.py 上限 5000` で変更）
- Driveが見えないときは手元に貯め、次にDriveが見えたときに合算して表示する

> **台帳に載るのはこのスクリプトを通した分だけ。** 本当の請求は
> Google Cloud Console → お支払い → レポート（SKU別）が正。月末に必ず突き合わせる。
> 誰がいくら使ったかを請求側で分けたいなら、**メンバーごとに別のAPIキーを発行する**のが確実。

### 6. plan.json を書いて、ドラフトを作る

```json
{
  "name": "試作編第2話",
  "sources": ["G:/マイドライブ/50日企画素材/7 5 試作",
              "G:/マイドライブ/50日企画素材/音声素材/試作編第2話"],
  "segments": [
    {"audio": "オープニング.m4a",
     "clips": [{"file": "オープニング.mp4", "offset": 0}],
     "telop": [{"at": 0.35, "lines": ["16日後に三宮に"], "y": 231},
               {"at": 1.6,  "lines": ["スープ屋を開く大学生"], "y": 1193}]},
    {"audio": "正直にいいます.m4a",
     "clips": [{"file": "IMG_1787_室内前かがみ落ち込み後ろ姿.MOV", "offset": 0.5, "dur": 3.5},
               {"file": "IMG_2886_室内ジャケット正面語り長尺2.MOV", "offset": 5.0}],
     "telop": [{"at": 0, "until": 3.1, "lines": ["正直に言います"]},
               {"at": 3.1, "lines": ["思ってたより", "うまくできませんでした"], "color": "yellow"}]}
  ],
  "se": [{"file": "ドーン.mp3", "seg": 1, "at": 3.1, "volume": 0.7}]
}
```

- `offset` = そのクリップの何秒目から使うか。`dur` を書かなければ残り時間を等分する
- `fit` は省略で cover（縦画面を覆う）。画面録画など切れてはいけない素材だけ `"fit": "contain"`
- `telop` の `until` を省くとそのセグメントの終わりまで。`y` の既定は1340（下1/3）
- `color` は `white`（既定）か `yellow`（強調行）。2行のうち下だけ黄色にするなら `"colors": ["white", "yellow"]`
- `size` は CapCut の文字サイズ（既定13）。「目標 50万円」のようなドーンと出す数字だけ 22 くらい。上に置くなら `y` を 300〜500 に
- `se` の `seg` は上から0始まりのセグメント番号
- 最初のクリップが `オープニング.mp4`・最後が `エンディング.mp4` でないと止まる。例外は `"no_op_ed": true`
- 効果音・OP/ED・フォントは `G:\マイドライブ\50日企画素材\_共通素材\` から自動で拾う。`sources` に書かなくていい

```bash
python scripts/make_draft.py plan.json
```

素材は `C:\Users\<自分>\Videos\リール素材\<企画名>\` に自動でコピーされる
（CapCutは開くたびに元ファイルを読むので、Driveやscratchpadを参照させてはいけない）。

mp4 も頼まれたら（納品先は `G:\マイドライブ\50日企画素材\完成動画\`）:

```bash
python scripts/render_mp4.py plan.json "G:/マイドライブ/50日企画素材/完成動画/<企画名>_完成版v1.mp4"
```

書き出したら 10〜15点フレームを抜いて目視（テロップの位置・黄色・黒帯・OP/ED）してから渡す。

#### ナレーションの一部を切りたいとき（言い間違い・古くなった日付など）

録り直しが要らないなら音声ファイル側で切る。**耳で探さず数字で決める**:

```bash
python -c "from faster_whisper import WhisperModel as W; m=W('small',device='cpu',compute_type='int8'); [print('%.2f-%.2f %s'%(w.start,w.end,w.word)) for s,_ in [m.transcribe('音声.wav',language='ja',word_timestamps=True)] for seg in s for w in seg.words]"
ffmpeg -i 音声.wav -af "aselect='not(between(t,2.60,3.45))',asetpts=N/SR/TB" 音声_修正.wav   # 途中を抜く
ffmpeg -i 音声.wav -af "atrim=start=2.20,asetpts=N/SR/TB" 音声_修正.wav                     # 頭を切る
```

切った音声は**別名で**素材フォルダに置き、plan の `audio` をそれに差し替える（元は残す）。
文字起こしの単語境界より 0.05〜0.1秒 余裕を持って切ると語尾が欠けない。

静止画を動画にしたクリップが音声より短いときは `tpad=stop_mode=clone:stop_duration=1.0` で最後のコマを延ばした別名ファイルを作る。

### 7. 渡す

**「CapCutを再起動すると一覧に出ます」を必ず伝える。**起動したままだと出てこない。

開いたら本人に**この5つを見てもらう**（1つでも違えば様式が崩れている）:

1. 最初がオープニング、最後がエンディングになっているか
2. テロップが丸ゴシックの太字（フォント「企業」）か。フォント欄が「システム」になっていたら古い `make_draft.py` で作ったドラフト。作り直す（新版は自動で「企業」を入れる）
3. 決めゼリフの行だけ黄色になっているか
4. 横長の素材に上下の黒帯が出ていないか
5. 効果音が3〜5個で、黄色の行や表情の変わり目に付いているか

そのうえで本人がやること: カットの尺の微調整・トランジション・エフェクト。

## 作り直しの注意

**ドラフトの上書きは、本人がCapCut上で加えた編集を全部消す。**
編集が始まったあとは上書きせず、

- 差し替え素材を `C:\Users\<自分>\Videos\リール素材\<企画名>\` に置いて、CapCut上で右クリック→素材の置き換え、
- または別名（`_v2`）で出す

## よくあるつまずき

| 症状 | 原因と直し方 |
|------|------------|
| CapCutに出てこない | 起動中に作った。**再起動する** |
| 「異常なパス」で開けない | `make_draft.py` を通していない（パス正規化とネイティブ化が要る） |
| 骨格ドラフトが無いと言われる | CapCutで新規プロジェクトを1つ作ってから再実行 |
| SegmentOverlap で落ちる | テロップの時間が重なっている。`until` を前倒しする |
| 素材時長超過で落ちる | `offset` が素材の尺を超えている。`scan_assets.py` で実尺を確認 |
| 映像が足りませんと出る | ナレーションのほうが長い。クリップを足すかCapCut上で静止延長 |
| 音がガサガサ | `.m4a` は自動でノイズ除去して取り込む。それでも残るなら録り直し |
| OP/EDが無いと言って止まる | plan の最初を `オープニング.mp4`、最後を `エンディング.mp4` にする。共通素材が無ければ `setup_check.py` |
| テロップのフォントが「システム」 | フォント情報が入っていないドラフト（2026-09-05以前の生成物）。新しい `make_draft.py` で作り直すと「企業」が入る。それでも既定ゴシックなら、そのPCのCapCutで一度フォント「企業」を選んでキャッシュさせてから再生成 |
| mp4 のテロップが細いゴシック | フォントのパスに日本語が入って ffmpeg が読めていない。`render_mp4.py` は ASCII パスにコピーして使う設計なので、`%TEMP%` に日本語が入っていないか確認 |
| テロップが既定のゴシック | このPCのCapCutにフォント「企業」がまだ無い。一度フォント一覧から「企業」を選べば次から自動で付く |
| 横長素材に黒帯 | `fit` を `contain` にしている。外す（既定の cover に戻す） |
| 素材が見つかりませんで止まる | `_共通素材` がDriveに無い、またはファイル名の表記ゆれ。`setup_check.py` で何が無いか出る |
